# pessoal/

Projetos pessoais, experimentos e protótipos fora do currículo acadêmico.

## Sobre

Esta pasta é destinada a projetos de aprendizado autônomo, scripts utilitários e qualquer código que não se encaixa nos projetos formais do curso.

## Como contribuir

Cada subpasta deve ter seu próprio `README.md` com:
- Descrição do projeto
- Dependências e como instalar
- Como executar
