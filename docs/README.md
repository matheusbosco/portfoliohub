# docs/

Documentação geral, anotações de aula e referências técnicas.

## Organização sugerida

| Subpasta | Conteúdo |
|----------|----------|
| `git/` | Comandos Git, fluxos de trabalho, cheatsheets |

| `python/` | Anotações de Python e SQL |

## Formato

Arquivos `.md` (Markdown) para texto e referências.  
Arquivos `.pdf` para materiais do curso que precisam ser preservados.
