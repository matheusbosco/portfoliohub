# portfoliohub

Repositório acadêmico criado no **Bootcamp I — Engenharia de Software (UniCEUB)**.

Objetivo: demonstrar domínio de versionamento com Git e GitHub, estrutura de projetos e publicação via GitHub Pages.

---

## Estrutura

```
portfoliohub/
├── academico/          # Projetos da faculdade
│   └── portfoliohub/   # Portfólio pessoal (v1.0)
├── pessoal/            # Projetos pessoais
├── docs/               # Documentação geral
└── README.md
```

## Como navegar

| Pasta | Conteúdo |
|-------|----------|
| [`academico/`](academico/) | Projetos desenvolvidos ao longo do curso |
| [`academico/portfoliohub/`](academico/portfoliohub/) | Página web do portfólio pessoal |
| [`pessoal/`](pessoal/) | Experimentos e projetos fora do currículo |
| [`docs/`](docs/) | Documentação de referência e anotações |

## Como rodar localmente

```bash
git clone https://github.com/matheusbosco/portfoliohub.git
cd portfoliohub/academico/portfoliohub
# Abra index.html no navegador ou use um servidor local:
npx serve .
```
